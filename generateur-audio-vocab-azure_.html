02

Clé API Azure Speech

Région + clé se trouvent dans le portail Azure, sur votre ressource « Speech ». Les deux sont nécessaires pour appeler l'API.

Azure n'expose pas le quota restant via cette API publique : renseignez-le manuellement si vous le connaissez (portail Azure → Metrics) pour activer la pause automatique. Sinon, laissez vide — le compteur de session continuera de s'afficher sans limite.

⚠️ Quota atteint sur cette clé. Changez de clé/ressource Azure ci-dessus puis cliquez sur « Vérifier la clé & charger les voix » — la génération reprendra automatiquement là où elle s'est arrêtée.

04

Portée & réglages

Un lot est aussi finalisé automatiquement dès ~35 Mo, même avant ce nombre de mots — pour éviter que Safari (surtout sur iPhone) ne recharge la page par manque de mémoire en compressant un trop gros ZIP d'un coup.

La génération se met en pause automatiquement dès qu'il reste moins de caractères que la prochaine tâche + cette marge, pour ne jamais dépasser le quota de la clé active.

Chargez le JSON pour estimer le volume de caractères.
