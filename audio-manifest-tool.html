Générateur de manifeste audio (sans code à exécuter)

Cet outil tourne entièrement dans ton navigateur : rien n'est envoyé nulle part, rien à installer. Il lit les noms de tes fichiers audio et prépare deux choses à glisser dans ton dossier Carnet.

1
Sélectionne ton dossier audio
Fichiers attendus : id_mot_categorie.mp3 (ex. 42_abandon_mot.mp3)
2
Télécharge le manifeste
Un fichier audio-index.json sera généré.
3
Range les fichiers dans ton dossier Carnet
Dans ton explorateur de fichiers (pas besoin de code) :
• mets audio-index.json téléchargé dans le dossier data/ du repo (remplace l'ancien s'il existe)
• copie tous tes fichiers .mp3/.wav dans le dossier audio/ du repo (glisser-déposer suffit)
4
Pousse sur GitHub
Ajoute, commit, push comme d'habitude (ou glisse les fichiers directement sur github.com si tu préfères l'interface web, sans terminal).
