🗜️ Minifier un JSON

Choisis un ou plusieurs fichiers .json (ex. depuis data/ de ton carnet). Tout se passe dans le navigateur, rien n'est envoyé nulle part. Chaque fichier est validé, minifié (espaces/retours à la ligne supprimés), et devient téléchargeable individuellement.

Touche ici pour choisir des fichiers JSON
ou dépose-les (sur ordinateur)
Astuce : sur iPhone, chaque téléchargement propose « Enregistrer dans Fichiers » — tu peux ensuite déposer le fichier minifié directement dans data/ sur GitHub via Add file → Upload files, à la place de l'original.
